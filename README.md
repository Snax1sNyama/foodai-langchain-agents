# NyamaNyamaAI: Мультиагентная система рекомендаций (LangChain + GigaChat + MCP)

## 📌 О проекте
Этот репозиторий содержит код клиентской части (Оркестратора) для проекта FoodAI. Система использует фреймворк **LangChain** для управления LLM-агентами и протокол **MCP (Model Context Protocol)** для вызова внешних инструментов.

## 🏗 Архитектура
В проекте реализованы следующие агенты:
*   **Location Agent**: Ищет рестораны поблизости, используя MCP-сервер.
*   **Validator Agent**: Проверяет рекомендации на безопасность и соответствие бюджету, защищая систему от **Prompt Injection** атак.

### Технологический стек:
*   **Язык**: Python 3.10+
*   **Оркестрация агентов**: LangChain, LangGraph
*   **Модель**: GigaChat (через API Cloud.ru)
*   **MCP-серверы**: Развернуты в облаке FastMCP Cloud.
